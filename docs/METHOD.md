# PolyXRD LFP 方法说明（算法与口径）

本文记录**软件实际在算什么**，以及每个选择的依据。凡涉及数值口径的地方都指明
代码位置，便于核对与复现；凡涉及经验阈值的地方都给出实测依据（`tools/diag_identify.py`
可复跑）。本文不是教科书综述：推导从简，口径从严。

---

## 1. 定位与纪律

单相 LiFePO4（橄榄石型，Pnma，No. 62，Z = 4）粉末 XRD 的常规处理与 Rietveld 精修。
软件把「是不是 LiFePO4」当成**闸门**而非建议：判定不过就不进入精修
（`lfp/core/refine/api.py::run_analysis` 抛 `NotLFPError`，界面同时锁死按钮）。

理由不是保守，而是 Rietveld 方法的性质：最小二乘总能找到一个极小值，即便结构模型
与样品无关——参数会照样收敛，Rwp 也未必难看，只是晶胞、尺寸、应变都没有物理意义。
判定因此必须在精修之前，且判据必须能说清「为什么不是」。

## 3. 前向模型

### 3.1 峰位

立方/正交晶系的 Bragg 条件按晶胞参数直接求 d，再转 2θ；峰位含零点项：

```
2θ_hkl = 2·asin(λ / (2·d_hkl)) + zero
```

反射表由晶胞 + 空间群对称操作生成并合并等价反射（`lfp/core/profile/lattice.py`），
每个反射带多重性 `n_merged`。双线（Kα1/Kα2）按 `resolve_wavelengths` 生成两条记录，
权重之和归一（`1/(1+r)`、`r/(1+r)`，默认 r = Iα2/Iα1 = 0.5），保证总积分强度守恒。

### 3.2 强度

```
I_hkl ∝ m_hkl · |F_hkl|² · LP(2θ) · W_PO(α) · exp(−B·s²) · Ω(2θ − 2θ_hkl)
```

- **原子散射因子**：Cromer–Mann 四高斯解析式
  `f(s) = Z − 41.78214·s²·Σᵢ aᵢ·exp(−bᵢ·s²)`（Cromer & Mann 1968）。
- **LP 因子**：Bragg–Brentano 粉末几何的 Lorentz–偏振合成 `(1 + cos²2θ)/(sin²θ·cosθ)`。
- **择优取向**：March–Dollase 权重 `W = (r²cos²α + r⁻¹sin²α)^(−3/2)`，默认沿 (020)
  惯习方向（压片样品常见），r = 1 时恒等于 1（Dollase 1986）。
- **温度因子**：整体各向同性 B，`exp(−B·s²)`；默认不精修（与尺寸强相关，易发散）。

### 3.3 峰形

仪器宽化用 Caglioti 关系给**高斯分量**，样品宽化（尺寸 + 应变）给**洛伦兹分量**，
两者按 Thompson–Cox–Hastings 合成：

```
Γ_G² = U·tan²θ + V·tanθ + W            (Caglioti 1958；θ = 2θ/2)
β_L  = Kλ/(D·cosθ) + 4ε·tanθ           (Scherrer 1918；Wilson 应变，K = 0.9)
Γ⁵   = Γ_G⁵ + 2.69269Γ_G⁴Γ_L + 2.42843Γ_G³Γ_L²
       + 4.47163Γ_G²Γ_L³ + 0.07842Γ_GΓ_L⁴ + Γ_L⁵
η    = 1.36603q − 0.47719q² + 0.11116q³,  q = Γ_L/Γ
```

（TCH 1987；实现见 `lfp/core/profile/forward.py::voigt_mix`）

峰形函数取 pseudo-Voigt `Ω = η·L + (1−η)·G`（单位峰高，`_pv_peak`），
这样峰高与积分强度的换算关系固定为 `H = A / (Γ·(1.06447 + 0.50633η))`，
便于按峰高做强度分解（R_Bragg 需要）。

低角不对称按 `s = asym/tanθ` 把左右半高宽分别缩放 `(1+s)`、`(1−s)`，
是轴向发散/样品穿透的一阶经验描述；`asym = 0` 时严格对称。

> 口径提醒：`lfp/core/profile/shape.py::caglioti`（家族 vendor 副本）里 `pos`
> 是按 2θ 直接取 tan 的，属另一套口径；本工程正式计算一律用
> `forward.caglioti_fwhm`（内部 `2θ/2`）。两者不可混用，勿用前者与文献 U/V/W 比较。

## 4. 最小二乘

### 4.1 变量投影

给定非线性参数（晶胞、零点、峰形、尺寸/应变、不对称、择优取向、B），
模型对「标度 + 背景系数」是**线性**的：

```
y_calc = c₀·Φ(2θ) + Σⱼ cⱼ·Bⱼ(2θ)
```

Φ 为归一化全谱 profile，Bⱼ 为背景基（Chebyshev 多项式或线性插值 tent）。
于是对线性系数可解析求解加权最小二乘（Golub & Pereyra 1973 的变量投影思想）：

```
c = (AᵀWA)⁻¹AᵀW y_obs,   W = diag(1/σ²)
```

外层的非线性残差只剩 (y_obs − ŷ)/σ 对非线性参数的依赖，条件数显著改善——
这是本软件能稳定收敛的主因，也是「背景与标度不必进优化器」的依据。

### 4.2 非线性层

`scipy.optimize.least_squares(method="trf")`，带参数边界（如 U ≥ 0、W ≥ MIN_W、
η ∈ [0,1]）；SciPy 不可用时回落到自写 Levenberg–Marquardt（`lm.py`）。
收敛判据用 ftol/xtol/gtol，并对多次重启（restart）保留最优解。

### 4.3 分阶段策略

一次性放开全部自由度在真实粉末谱上极易发散（晶胞错了会让优化器把峰「撑宽」去
覆盖错位峰，卡在 Rwp 20 % 以上的局部极小）。因此按解耦顺序分阶段
（`api.py::_stage_configs`）：

| 阶段 | 放开 | 目的 |
|---|---|---|
| 1 | 仅线性层（标度 + 背景） | 定标度与背景 |
| 2 | 零点 + 尺寸/应变 + 不对称（η） | 定峰位与峰宽 |
| 3 | + 晶胞 a/b/c | 定晶胞 |
| 4 | + 用户勾选的 U/V/W、B、择优取向 | 精细收敛 |

最终取**所有阶段中 Rwp 最小**的解：后一阶段偶尔会破坏拟合（B 与 U/V/W 同时放开时
尤甚），不能无条件采纳最后一个阶段。

### 4.4 强度归一化与不变性

内核把谱归一化到最强峰 ≈ 1000 计数的**工作尺度**再优化（`_Model.norm`），
σ 同除该因子；出口再乘回原尺度。这不是数值洁癖：实测未归一化时（合成谱峰高
4.5×10⁹）优化器在坏条件数下发散到 GOF ≈ 10³。归一化后
`(Δy/k)/(σ/k) = Δy/σ`，R 因子与 k 无关——**归一化不改变任何报告指标**，
只改变优化的数值条件。

## 5. R 因子口径

按 GSAS-II 口径（Toby & Von Dreele 2013），背景计入计算谱：

```
w_i   = 1/σ_i²,  σ_i = √max(y_i, 1)              (计数统计)
Rwp   = 100·√(Σw(y_o − y_c)² / Σw·y_o²)
Rp    = 100·Σ|y_o − y_c| / Σy_o
Rexp  = 100·√((N − P) / Σw·y_o²)
χ²    = (Rwp/Rexp)²,   GOF = Rwp/Rexp = √χ²
```

`P` 计可调参数总数（非线性参数 + 标度 + 背景项数），因此**放开更多参数会让 Rexp
变小、χ²/GOF 变大**——GOF 不是「越小越好」，1 附近才是「残差与泊松噪声相当」。

**R_Bragg**（`lfp/core/refine/rbragg.py`）用 profile-partitioned 方案：按各反射在
该处的峰高振幅分摊重叠区的计算强度，再对比各自的积分强度；求和时乘步长换算成
「计数·度」。因此 R_Bragg 与 Rwp 不必同量级——前者只看结构模型对**积分强度**的
描述，后者被峰形与背景误差主导。

> 判读纪律：Rwp 绝对值与计数统计强相关，同一条谱快扫时 Rexp 本身就高。界面因此
> 同时给 GOF 档位：Rwp > 15 % 但 GOF ≤ 1.2 时提示「拟合已充分，Rwp 高是计数所限」
> （`lfp/gui/verdict.py`），而不是一律判「拟合差」。

## 6. 物相判定

### 6.1 两条系统偏差

真实样品与参考模型之间必然存在两类系统偏差，判定必须能吸收它们：

- **零点/样品位移 dz**：整体平移，搜索 ±0.20°；
- **晶胞失配 δ = Δd/d**：随 2θ 增大的偏移，`sinθ_obs = sinθ_ref/(1+δ)`，
  即 `Δ2θ ≈ −(360/π)·δ·tanθ`；搜索 ±1 %（覆盖 LFP↔FePO4 约 0.6 % 的晶胞差）。

### 6.2 为什么不能只用网格

覆盖率对 dz 是**阶跃函数**：只要参考峰落在实测峰 ±tol 内就算命中，于是 (dz, δ) 平面
上存在大片覆盖率相同的平台（宽度约 2·tol）。在平台上取「覆盖率最大」等于随机落点——
实测真值 +0.02° 会被报成 −0.12°，真值 0.15° 被报成 0.04°（详见
`docs/VALIDATION_v1.0.0.md` §4 的修复记录）。

因此搜索分两步：

1. **网格定对应关系**：0.02°×0.001 网格，只用来确定「哪条参考峰对上哪个实测峰」；
2. **最小二乘定数值**：用配对做加权（√相对强度）最小二乘解 (dz, δ)，再按新值重配对，
   交替迭代至收敛（`_refine_offset`）；从网格前 4 个候选各跑一遍，取优。
   配对里错配一档的离群对按 `|r| > max(2.5·1.4826·MAD, 0.02°)` 迭代剔除两轮。

匹配本身用「按 |Δ2θ| 全局排序后占位」而非逐参考峰取最近邻：后者会让先到的弱峰抢走
后面强峰本该占用的实测峰（LFP 在 30–40° 一带参考峰间距可小于容差）。

### 6.3 四条判据

| 判据 | 定义 | 阈值 |
|---|---|---|
| 覆盖率 | 命中参考峰的强度权重占比（权重 = 计算相对强度） | ≥ 0.70 |
| 前三强 | 数据范围内计算谱最强 3 条线各自有实测峰对应 | 3 / 3 |
| 未解释强度 | 未命中的实测峰强度占比；可作为某命中峰的 Kα2 卫星者豁免 | ≤ 0.35 |
| 模型充分性 | 配对峰加权峰位残差 RMS / 位置容差 | ≤ 0.45 |

位置容差 `tol = clip(0.35×实测中位 FWHM, 0.15°, 0.30°)`：下限防止用峰宽当容差把
多相/无定形包「凑」成本相，上限防止宽容差放行错相。Rietveld 前的定性判定宁可严格
（漏判可由用户手动放行，错判会一路精修出无意义晶胞）。

**阈值 0.45 的来历**（`tools/diag_identify.py` 实测，见验证文档）：

- 合格侧：合成 plain 0.19、各向同性 +0.4 % 0.15、真实 LiFePO4 0.14、磷酸铁锂#1 0.13；
- 需拦下者：`a+1 %/b−0.3 %` 覆盖率 0.731、前三强 3/3、未解释 0.315（三条全过）
  残差比 0.56；`a+0.6 %/b−0.6 %` 覆盖率 0.755、残差比 0.53。

取 0.45 使合格侧保有 2 倍余量，同时拦住「只靠覆盖率会漏网」的形变样本。

### 6.4 预拟合晶胞

命中峰对 (2θ_obs, hkl) 代入
`sin²θ = (λ/2)²·(h²/a² + k²/b² + l²/c²)`，对 (1/a², 1/b², 1/c²) 线性，
加权最小二乘（权重 √相对强度）解得三轴比例，作为精修起点。仅在三个解均为正且
相对原晶胞偏离 < 5 % 时采纳。这一步是分阶段精修第 3 阶段能稳定收敛的前提。

## 7. 谱图处理

| 处理 | 方法 | 注意点 |
|---|---|---|
| 平滑 | Savitzky–Golay（窗口必为奇数） | 窗口过大会削峰高，进而影响 R 因子 |
| 背景 | SNIP 迭代削峰 / 多项式 / 端点线性 | 端点线性只用于「看」，不改变强度分布 |
| 去 Kα2 | Rachinger 剥离 | 递推必须**低角→高角** |

Rachinger 剥离的递推方向是易错点。由 `y_obs(2θ) = y₁(2θ) + r·y₁(2θ − Δ)` 反解得
`y₁(2θ) = y_obs(2θ) − r·y₁(2θ − Δ)`：Kα1 峰位在 Kα2 的低角侧，故必须先算低角、
再往高角递推（原地 Gauss–Seidel）。方向写反时高角处的 Kα1 强度会被反复减掉而变负
（实测 3 轮后 187、5 轮后 −240），且结果随迭代次数漂移；方向正确时 1/2/3 轮结果
恒等（`tests/test_processing.py` 锁死）。

## 8. 寻峰

`find_peaks`（局部极大 + prominence）给候选，再逐峰做 pseudo-Voigt + 线性背景的
有界最小二乘精修峰位/峰高/FWHM/η。为避免「宽胖峰包住整个窗口」的退化解，位置边界
收紧到 ±(0.4×窗口半宽, ≤0.25°)，并设质量闸门：位置偏离初值 > 0.4×窗口 + 0.02°、
拟合 R² < 0.5、峰高 > 2×原始极差、FWHM ≤ 0 时退回解析估计。最后按 SNR 过滤 +
位置去重。

## 9. 对称性映射

不枚举 230 个空间群，而用 ITA 编号分段映射：编号 → 点群 → 劳厄群 → 布拉维格子
（`lfp/core/symmetry.py`）。例：Pnma（62）→ 正交晶系 / mmm / D2h / oP。
空间群符号规整为紧凑形式（`'P n m a'` → `Pnma`），式量优先取
`_chemical_formula_structural`。
